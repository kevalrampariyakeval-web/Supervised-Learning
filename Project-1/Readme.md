📌 About the Project
Predictive Insight Engine is a machine learning project that predicts house prices using property-related features.
This project explores different regression techniques, evaluates their performance, and studies how machine learning models can identify relationships between property features and house prices.
🎯 Project Objectives
Understand and prepare the house price dataset.
Implement Simple Linear Regression.
Build a Multiple Linear Regression model.
Explore Polynomial Regression.
Understand Gradient Descent optimization.
Evaluate model performance using regression metrics.
Analyze overfitting, underfitting, and the bias–variance trade-off.
Compare model performance and summarize the findings.

📏 Evaluation Metrics
The following metrics are used to evaluate regression models:
MAE: Mean Absolute Error
MSE: Mean Squared Error
RMSE: Root Mean Squared Error
R² Score: Measures the variation explained by the model.
Adjusted R² Score: Adjusts R² according to the number of input features.
